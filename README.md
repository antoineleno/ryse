# RYSE Strategy & Foresight

Premium React site for RYSE — political and strategic advisory across West Africa.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion
- Bilingual EN / FR

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/pages` — routed pages (Home + one page per nav item)
- `src/sections` — full page content blocks
- `src/components` — shared UI (Header, Layout, etc.)
- `src/i18n/content.ts` — English & French copy
- `static/media` — imagery and board portraits

## Routes

`/`, `/about`, `/expertise`, `/sectors`, `/approach`, `/projects`, `/where`, `/board`, `/experts`, `/contact`
